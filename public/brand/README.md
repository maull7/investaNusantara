# NusantaraNews — Brand Assets

Nama brand: **NusantaraNews** (tanpa 360).

## Warna

- Merah: `#A50E1E`
- Navy: `#0A1C36`
- Putih: `#FFFFFF`

## Penggunaan

- `logos/logo-horizontal.svg`: header website berlatar terang
- `logos/logo-horizontal-white.svg`: header berlatar gelap (ikon putih)
- `logos/logo-stacked.svg`: komposisi vertikal
- `icons/icon-red.svg`: simbol tanpa latar
- `icons/icon-on-red.svg`: ikon dengan latar merah
- `favicon.svg`, `favicon.ico`: favicon website
- `pwa/apple-touch-icon.png`: iOS
- `pwa/icon-192.png` dan `pwa/icon-512.png`: PWA

SVG wordmark memakai font Poppins dengan fallback Arial. Untuk hasil konsisten, pasang Poppins di website; bila dikirim ke percetakan, konversi teks ke outline di Figma/Inkscape/Illustrator.

Contoh HTML:

```html
<link rel="icon" type="image/svg+xml" href="/favicon.svg" />
<link rel="icon" type="image/x-icon" href="/favicon.ico" />
<link rel="apple-touch-icon" href="/apple-touch-icon.png" />
```

Catatan: monogram SVG dalam paket adalah interpretasi vektor geometris dari arah desain pada visual brand board, bukan tracing piksel identik dari mockup.
